A NOTE ON THE MONO FILES
  In the original artwork "Upholstery & Fabric Revival" is drawn at about
  30% opacity — correct as light grey in the full-colour lockup, but useless
  for 1-colour work. Every -white and -black file has that line lifted to
  full ink so it stitches, stamps and reads on navy. The full-colour files
  are untouched.

DON'T
  Never re-type "Lefties" in any font — always use these image files
  Never add gloss, extra gradients or drop shadows
  Never stretch or condense
  Never recolour outside the palette above

STILL RASTER, NOT VECTOR
  These are high-resolution PNGs made from the PNGs you sent. For signage,
  vehicle wrap or embroidery a signwriter will want true vector. Ask whoever
  drew the original for the .ai or .eps file, send me that, and the whole kit
  can be re-cut as SVG/PDF at any size.
