# Whale / "L" shape concept

**Status: exploration. Not approved, not in use.**

An alternative brand direction dated 23 August 2026, built around an "L"
that reads as a whale form. It is unrelated to the approved water-droplet
identity in `/brand`, which remains the live brand.

Nothing on the site references these files. They are committed here so the
direction is preserved and versioned while it is being considered.

## Files

All nine variants as supplied, unedited. They fall into four artwork
groups, most of which exist as both a transparent (RGBA) and an opaque
(RGB) export:

| Artwork | Dimensions | Transparent | Opaque |
|---|---|---|---|
| Wide lockup | 2381 x 1019 | `Brand Shape L Whale Graphic.PNG` | `...Graphic 2.PNG` |
| Slim horizontal | 2363 x 425 | `...Graphic 4.PNG` | `...Graphic 3.PNG` |
| Stacked / portrait | 1113 x 1222 | `...Graphic 5.PNG` | `...Graphic 6.PNG` |
| Standard horizontal | 2540 x 906 | `...Graphic 8.PNG`, `...Graphic 9.PNG` | `...Graphic 7.PNG` |

All nine are distinct files; 8 and 9 share dimensions but differ in content.

## If this direction is chosen

Same limitation as the current brand: these are raster, not vector. Have
the chosen variant redrawn as SVG before committing to any large-format
print or vehicle livery. See `/brand/BRAND.md` section 1.
